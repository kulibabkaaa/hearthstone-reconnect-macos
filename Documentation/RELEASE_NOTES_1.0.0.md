# HS Reconnect 1.0.0

Initial public release for native Hearthstone Battlegrounds on macOS.

## Highlights

- Reconnect your current Battlegrounds game immediately with a local Network
  Extension.
- Use Command-Shift-W by default or record and remember your own global
  shortcut.
- Open quietly with Hearthstone and choose whether HS Reconnect appears in the
  Dock.
- Recover easily if Network Extension approval is dismissed: setup guidance
  and an **Open System Settings** button remain available until approval is
  complete.
- Remove the app, Network Extension, settings, installer receipt, and Desktop
  shortcut with the built-in uninstaller.

## Compatibility

- macOS 13 or later
- Apple silicon and Intel Macs
- Native macOS Hearthstone

The download is signed with Apple Developer ID, notarized by Apple, and contains
the guided installer. HS Reconnect is free and contains no analytics,
advertising, telemetry, or project-server connection.

HS Reconnect is unofficial and is not affiliated with Blizzard Entertainment.
Use it at your own risk. Game behavior and policies may change.
