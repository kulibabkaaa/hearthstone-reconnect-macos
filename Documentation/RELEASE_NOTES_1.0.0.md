## Install

1. Download and open `HS-Reconnect-1.0.0.dmg`.
2. Open **Install HS Reconnect.pkg** and complete the installer.
3. Open HS Reconnect and approve the one-time macOS Network Extension and
   network configuration requests.

If you dismiss the first permission message, reopen HS Reconnect and select
**Open System Settings** beside the setup message.

## What you get

- Command-Shift-W as the default global shortcut, with support for recording
  and remembering your own shortcut.
- Optional quiet opening with Hearthstone.
- Menu bar operation with a Dock icon you can show or hide.
- A built-in uninstaller that removes the app, Network Extension, settings,
  installer receipt, and Desktop shortcut.

## Compatibility

- macOS 13 or later
- Apple silicon and Intel Macs
- Native macOS Hearthstone
