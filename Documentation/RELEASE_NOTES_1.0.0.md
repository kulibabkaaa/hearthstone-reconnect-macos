# HS Reconnect 1.0.0

Initial public release for native Hearthstone Battlegrounds on macOS.

- Immediate reconnect using a local Network Extension
- Command-Shift-W default global shortcut
- Custom shortcut recording and persistence
- Optional quiet opening with Hearthstone
- Menu bar and Dock controls
- Desktop shortcut installed automatically
- Apple silicon and Intel support
- macOS 13 or later

HS Reconnect is unofficial and is not affiliated with Blizzard Entertainment.
Use it at your own risk. Game behavior and policies may change.
