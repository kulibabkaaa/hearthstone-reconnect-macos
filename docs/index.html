HS Reconnect: the native Hearthstone reconnect tool for Mac.

HS Reconnect is a free Hearthstone Battlegrounds reconnect tool for Mac. One shortcut closes the current game connection so Hearthstone can reconnect immediately.

Download for Mac Install guide

macOS 13+ · Apple silicon and Intel · Version 1.1.0

One clear action

Press Command-Shift-W during a match.

Keep HS Reconnect running alongside native Hearthstone. The shortcut works globally and can be changed inside the app.

Get started

Install in four steps.

  1. 01

    Download and open the signed disk image.

  2. 02

    Open Install HS Reconnect.pkg and complete the installer.

  3. 03

    Open HS Reconnect and approve the Network Extension when macOS asks.

  4. 04

    Launch Hearthstone and press Command-Shift-W during a match.

Updating? Do not uninstall first. Run the new installer over the existing version, then reopen the app. Your saved shortcut and startup preferences remain in place. Approve the replacement Network Extension or restart only if macOS asks.

Local and transparent

Built for native Hearthstone on Mac.

The app uses a local macOS Network Extension and passes Hearthstone game traffic through unchanged. It does not inspect or save traffic content.

No account, analytics, advertising, telemetry, remote crash reporting or project server is required. Public releases are signed with Apple Developer ID and notarized by Apple.

Common questions

Hearthstone reconnect tool for Mac FAQ

Does it support Apple silicon and Intel Macs?

Yes. HS Reconnect supports both architectures on macOS 13 or later.

Does it work with Windows or CrossOver?

No. Version 1.1.0 supports the native macOS version of Hearthstone.

Should I uninstall the old version before updating?

No. Run the new installer over the existing version. Uninstalling is only a troubleshooting fallback because it removes saved settings.

Why does macOS request Network Extension permission?

The one-time approval allows HS Reconnect to handle the native Hearthstone game connection locally and close it when you request a reconnect.
